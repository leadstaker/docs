Este guia leva você de zero a um contato criado pela API, com o registro visível no dashboard.

## Antes de começar

Você precisa de um projeto no Leadstaker e de acesso de membro a ele. Se ainda não tem, [crie sua conta](https://app.leadstaker.com).

## 1. Gere uma chave de API

No dashboard, acesse as **configurações do projeto** e clique em **gerar token**.

Guarde a chave assim que ela aparecer: ela não é mostrada de novo. Detalhes em [Autenticação](/api-reference/authentication).

## 2. Confirme que a chave funciona

```bash
curl https://n-api.leadstaker.com/v1/contacts \
  -H "x-api-key: SUA_CHAVE"
```

Uma resposta `200` com um envelope `{ "data": [...] }` significa que a chave está válida e já escopada no seu projeto. Um `401` significa chave errada ou vencida.

## 3. Descubra os campos do projeto

Um contato no Leadstaker não tem colunas fixas: nome, telefone e o resto são **campos** configuráveis por projeto. Antes de criar alguém, veja quais existem:

```bash
curl "https://n-api.leadstaker.com/v1/fields?entityTypes=CONTACT" \
  -H "x-api-key: SUA_CHAVE"
```

Anote o `id` dos campos que você vai preencher.

## 4. Crie um contato

```bash
curl -X POST https://n-api.leadstaker.com/v1/contacts \
  -H "x-api-key: SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "fields": [
      { "fieldId": "ID_DO_CAMPO_NOME", "value": "Maria Andrade" },
      { "fieldId": "ID_DO_CAMPO_TELEFONE", "value": "+5551999999999" }
    ]
  }'
```

<Note>
  Esse endpoint faz upsert. Se já existir um contato equivalente, a resposta é `200` com o registro existente em vez de `201` com um novo. Use o status para saber o que aconteceu.
</Note>

## 5. Encontre o contato de volta

```bash
curl -G https://n-api.leadstaker.com/v1/contacts \
  -H "x-api-key: SUA_CHAVE" \
  --data-urlencode "search=Maria" \
  --data-urlencode "[limit]=10"
```

A gramática completa de filtros, ordenação e paginação está em [Filtros, ordenação e paginação](/api-reference/listing).
